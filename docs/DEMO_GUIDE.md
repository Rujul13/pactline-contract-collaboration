# Pactline demo guide

## Five-minute walkthrough

1. Open the owner workspace. The generic **Sample Services Agreement** is ready automatically.
2. Edit any paragraph and save it to demonstrate direct owner drafting and version history.
3. Select **Share client access** and copy the review link, username, and password.
4. Open the review link in a private browser window. Sign in as the client and propose a replacement for one paragraph.
5. Return to the owner workspace. Accept or reject the proposal and show the attributed audit activity.
6. With no proposals pending, record the owner's agreement. Then record the client's agreement on the same version.
7. Download the locked final DOCX from either workspace. Both downloads represent the same agreed version.
8. Use **Reset generic demo** before the next presentation.

## Generic sample credentials

- Username: `client.reviewer`
- Password: `ReviewDemo!2026`

These credentials protect demonstration data only and are intentionally shared. Never upload a real document into the generic sample. The application enforces this rule; use **New contract** for private files.

## Private-document flow

Choose **New contract**, enter a title, and upload a `.docx` file up to 15 MB. Then use **Share client access** once to generate contract-specific reviewer credentials. Store the displayed temporary password before closing the dialog.
